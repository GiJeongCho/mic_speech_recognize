# Mic Speech Recognize (음성 동기화 및 화자 분리 도구)

이 도구는 여러 개의 마이크에서 녹음된 오디오 파일(.wav) 간의 시간 차이를 자동으로 정렬(Synchronization)하고, 각 시점마다 가장 목소리가 큰 채널만 남기고 나머지는 소거(Muting)하여 화자를 분리하는 Python 스크립트입니다.

## 주요 기능

1.  **자동 타임라인 동기화**: 상호 상관 분석(Cross-correlation)을 통해 여러 녹음 기기 간의 시작 시간 차이를 계산하고 정렬합니다. 성능을 위해 초반 4분(설정 가능) 데이터와 저해상도 리샘플링을 활용합니다.
2.  **다중 채널 정렬**: 가장 늦게 녹음이 시작된 기기를 기준으로 모든 파일을 잘라내고 길이를 맞춥니다.
3.  **다수결 원칙 스무딩 (Majority Voting Smoothing)**: 0.1초 단위로 RMS(에너지)를 계산하여 승자 화자를 판별하며, 투표 기반 필터를 통해 짧게 튀는 노이즈나 잘못된 판별을 보정합니다.
4.  **개별 클린 오디오 생성**: 각 파일에서 해당 화자가 주 화자로 판별된 부분만 남기고 나머지는 묵음 처리하여 저장합니다.

## 설치 요구 사항

이 스크립트를 실행하려면 다음과 같은 라이브러리가 필요합니다.

pip install numpy librosa soundfile scipy## 사용 방법

1.  **파일 준비**: 분석하고자 하는 `.wav` 파일들을 특정 디렉토리에 모아둡니다.
2.  **경로 설정**: 스크립트 내 `WORK_DIR` 변수를 오디오 파일이 위치한 경로로 수정합니다.
    WORK_DIR = "/home/pps-nipa/NIQ/fish/mic speech_recognize/음성테스트데이터"
    3.  **스크립트 실행**:
    python "mic speech_recognize.py"
    ## 주요 설정 파라미터 (Settings)

스크립트 상단의 설정을 통해 동작을 조정할 수 있습니다.

*   `CHUNK_DURATION`: 화자 식별 단위 (기본값: 0.1초)
*   `SYNC_DURATION`: 동기화 계산 시 참조할 앞부분 시간 (기본값: 240초)
*   `VOTING_SIZE`: 스무딩을 위한 문맥 확인 범위 (기본값: 15 chunks, 약 1.5초)
*   `SR`: 저장 및 처리용 샘플 레이트 (기본값: 16,000Hz)

## 출력 결과

처리가 완료되면 `WORK_DIR` 내에 `processed_result_final` 폴더가 생성됩니다.
*   `clean_파일명.wav`: 원본 파일에서 본인의 목소리만 강조되고 나머지 구간은 묵음 처리된 파일입니다.

## 주의 사항
*   분석할 `.wav` 파일은 최소 2개 이상이어야 합니다.
*   파일 이름이 `processed_` 또는 `clean_`으로 시작하는 파일은 분석 대상에서 제외됩니다.
